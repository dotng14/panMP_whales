# Site H deployments

Times are the `YYMMDD_HHMMSS` stamps in the wav file names under `/mnt/sda/SiteH`. The first time is the earliest file in that deployment. The last time is the start of the latest file, so the recording continues past it by the length of that file. The span is the number of days between those two stamps. Days since the previous deployment are measured from the previous deployment's last file to this deployment's first file. A negative value means the two deployments overlap. Disks are the numbered instrument disks; the `df20` and `df100` copies of one disk count once.

Sites 19–25, 28, 33, 39, 42, 43, and 60 are not on this disk. The site numbers that are present follow the recording dates.
